Пропуски:

1. Upstream-тест `test_dedoc_tree_to_contract_preserves_table_order` импортирует
   `dedoc_service`, отсутствующий в репозитории. Он выполняется при наличии внешнего пакета;
   без него теперь использует явный `pytest.importorskip`. До этой правки общий прогон падал
   именно на ModuleNotFoundError. Функциональность внешнего Dedoc этим не подтверждается.
2. `test_actual_worker_stopped_on_memory_budget`: в текущей среде `psutil.Process()` возвращает
   NoSuchProcess для собственного PID. Тест не может измерить реальный RSS и условно пропущен;
   в обычном хостовом окружении он остаётся активен. Лимитирование ресурсов demo не проверено.

В core-прогоне присутствует одно предупреждение совместимости Starlette TestClient/httpx.
HTTP-контрактные тесты проходят; миграция upstream на иной тестовый клиент в эту задачу не входит.

## Что именно проверяют новые тесты

- NFC/пробелы без потери регистра и технических обозначений; raw и processed query.
- Однократное применение query_transform и обязательная версия трансформации.
- Пустой/нестроковый/слишком длинный запрос отклоняется до inference.
- Сохранение точного документного embedding_text, ID, source spans и всех метаданных.
- Пакетная обработка, порядок результатов, deduplication, ограничение размера кэша.
- Разделение кэша по purpose и revision, защита от изменения возвращённого списка.
- Проверка размерности/NaN/Inf/zero/boolean; L2-нормализация.
- Согласование provider/tokenizer/profile; запрет незакреплённых ревизий.
- BGE-M3 1024D без префиксов E5/BGE v1.5; подготовка manifest и конфликт каталога модели.
- Реальные TXTParser, ChunkingService, SQLiteManifest, IndexingService,
  InfinityEmbeddingProvider и QdrantVectorStore в одной проверке с mock HTTP-сервисами.
- Префиксы добавляются один раз, Qdrant получает unit vector и исходный payload;
  фильтры tenant/space сохраняются.
- Экспериментальный Fusion-envelope не получает автоматическое разрешение на индексацию.
- Async-вызов, закрытие провайдера и повторный close.
- nDCG/MRR/Recall по известным примерам, macro average, отсутствие результатов,
  неизменность Recall@50 при перестановке кандидатов, медиана/p95, некорректные qrels/ID.

## Пределы результата

Это проверка реализации и совместимости с конкретным upstream snapshot.
Основной репозиторий GitLab из презентации не был предоставлен для чтения, его реальные
интерфейсы и история не проверены. Не заявляются финальный командный merge, remote CI,
боевой деплой, реальные VRAM/latency или улучшение поиска.

Архив содержит Git bundle и patch для воспроизводимого переноса.
Запуски pytest сохранены в `transfer/validation/` архива. Bundle восстанавливается локально,
его feature-дерево сравнивается с исходниками, patch применяется к исходной базе без конфликтов.
